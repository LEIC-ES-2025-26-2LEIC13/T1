# Sprint 1 - Change Log

## New Features Implemented

### Core Authentication & User Management
- **Account Creation** - Users can now create new accounts with email and password registration
- **Login Authentication** - Secure authentication system allowing users to log in to their accounts

### Project Management
- **Creation of Project Board** - Users can create new projects with a given name and description
- **Invite Members to Project** - Users can invite other existing users to projects (with validation to prevent self-invites and duplicate memberships)
- **Join Workspace via Invite** - Users can join projects by accepting invites from other users

### User Interface
- **Initial UI Improvements** - Enhanced visual design and user experience across the application

### Known Limitations
- Tasks created within project boards currently have no database persistence
