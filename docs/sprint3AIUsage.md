# Sprint 3 AI Usage

## Tests
* Github Copilot and Claude were used to help write new tests and correct existing ones, inside the `__tests__/` directory.
* The tests were reviewed and modified, if necessary, by the team.

## Feature implementation
* Copilot's agent mode was used to help developing parts of new features during this sprint, mostly related to the UI such as admin pages and specific UI components.

## Bug fixing
* Gihtub Copilot was used for bug fixing, by suggesting potential causes for the bugs and possible solutions to fix them.

## Database logic
* Github Copilot was used to help develop some of the database logic for project template creation, deletion and modification and also for aiding in the development of the task, column and project reordering logic (drag and drop), by taking into consideration the current database structure.
