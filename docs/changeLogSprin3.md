# Sprint 3 - Change Log

## New features

### Task-level

* User can assign itself to tasks.
* Edit tasks name, description, label and assignees after creation.

### Project-level

* Edit project name and description after creation.

### Template-level

* Creation of templates that are like projects but come with pre-filled columns and tasks based on previous L.EIC projects.
* Hints on templates tasks to help guide users on how to deal with that task.
* Possibility to make suggestions based on a template.
* Admin can view suggestions read them and then delete them.

### Admin-level

* Admin accounts are now stored in Firestore and verified on login.
* Admin dashboard to create templates and view suggestions.
* Creation of templates are just like projects, but with the option to add hints to the tasks and without the option to assign members.

### User-level

* Built-in user profile page where users can view their email and username.
