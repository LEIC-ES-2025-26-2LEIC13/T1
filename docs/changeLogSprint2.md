# Sprint 2 - Change Log

## New features

### Column-level

* Creation of columns within projects. Inside these columns, tasks can be created.
* Edit the name of the columns.
* Deletion of columns (and all the tasks inside them).

### Task-level

* Creation of tasks with name, description, label and assignees, with database integration.
* Deletion tasks (finishing them).
* Add labels to tasks to help categorise them.
* Assign tasks to project members.
* View all the tasks assigned to a user in the "My Tasks" tab.
* Move tasks between and within columns.

## Project-level

* Deletion of projects (with all its columns and tasks).
* Possibility to see the members of a project.
* Possibility to kick members from a project.
* Possibility to leave a project.

### UI-level

* New UI design for the entire app, with a consistent color palette and improved styling.
* Custom alerts that match the app theme.
* New intro page for first-time users.
